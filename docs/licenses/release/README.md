# 固定版本许可补充材料

`../release-sources.json` 是补充材料的版本、来源、SHA-256 和类型索引。打包优先采用实际 npm 包内许可，其次采用嵌套资源或经显式映射的同源父包许可；仅在没有这些正文时使用本目录补充文件。所有索引记录必须映射到包内真实、非空、非符号链接的正文文件。

saxes 6.0.0 的 LICENSE 来自索引中固定 Git 提交的上游原文件。其他 `publisher-declaration-with-standard-text-and-notice` 文件来自该版本的 npm 许可证声明、实际发布包作者/仓库信息及官方 SPDX JSON 的完整 licenseText。文件明确说明来源；标准条款中的版权占位符保持原样，未虚构年份或权利人。fontkit 2.0.4 发布包没有 LICENSE 正文，不能把这里的补充条款称为其原始 LICENSE。

本目录服务于本地候选的正文映射和可追溯性。它不证明每一嵌套字体、二进制、NOTICE、版权或源码提供义务均已满足，也不构成法律意见。公开 GitHub Release/二进制分发前，需核实这些事项，特别是涉及 LGPL/MPL 等许可的传递资源。未获得原始声明的条目不得在发布说明中写成“上游完整许可已核验”。
