# 已知限制

- 当前暂时只支持 Mac / Apple Silicon，实测 macOS 26.2 arm64。Windows、Intel Mac 和 Linux 暂不支持；其他 macOS、干净系统安装、签名/公证与五位真人新用户试用待验。未经这些门禁不能称正式跨平台发行。
- 使用 OpenAI Chat Completions 兼容协议；各厂商原生协议、额外头、OCR、原版面编辑和复杂 Office 内容不支持。模型在固定合成服务上的通过不证明真实语义质量。
- Key 默认本次使用，可选 macOS Keychain；其他系统尚无凭据安全存储。普通参数落盘，浏览器没有记住密码。SDK 专用子进程的 Key 环境变量对同一系统用户可见。
- 项目删除保留完成交付的 ZIP、冻结记录、报告与迁移备份，不能用作彻底擦除。暂存清理失败会提示并在启动重试；没有应用内逐份历史产物删除或整库备份按钮。
- 损坏删除日志保留待人工检查，不阻断其他项目。新的模型会话有归属记录；旧版未知目录、符号链接及仍有活进程的会话保留，无法确认退出时阻止新模型调用。不能把“删除项目”当作强制杀进程或彻底擦除工具。
- 部分生产依赖的发布包缺少原始许可正文，候选提供版本绑定的发布声明/NOTICE/SPDX 补充条款，来源明示。文件映射检查不等于法律合规；公开分发前仍需上游版权、资源和源码提供义务复核。
- 候选包因 Harness 带 Office 等传递依赖较大；本轮完整保留生产依赖，不通过猜测删包缩减。
- 不保证联网模型结果、token 费用或耗时。仅明确 429 有应用层最多两次重试；没有结构化 Retry-After，其他错误需手动重试。
- 浏览器下载结束不能证明用户在保存对话框中保存成功。服务端 completed 表示包已核验，客户端取消不会改变这个事实。
- 不支持同一数据目录多服务、网络共享盘或公网访问。默认端口 4317 已占用时启动器给出错误，不自动关闭原服务。
- 发行候选不包含自动更新、托盘、开机自启或跨平台安装向导。停止服务使用启动器按钮或源码终端 Ctrl+C。
