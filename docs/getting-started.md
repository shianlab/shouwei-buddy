# 使用指南

当前仅支持 **Apple Silicon Mac**，实测 macOS 26.2。Windows、Intel Mac 和 Linux 暂不支持。本指南对应 0.1.0-rc.1 源码预览版。

## 安装与启动

安装 Node.js 24.15.0（含 npm），然后：

```bash
git clone https://github.com/shianlab/shouwei-buddy.git
cd shouwei-buddy
npm exec --yes --package=pnpm@11.28.5 -- pnpm install --frozen-lockfile
npm exec --yes --package=pnpm@11.28.5 -- pnpm start
```

首次安装需要联网。启动会编译本地服务和界面，随后打开浏览器访问 http://127.0.0.1:4317。网页不需要账户；当前不提供公网部署。

端口已被其他服务使用时，不要结束不认识的进程。可在自己的启动命令前指定 `SHOUWEI_PORT=4319`，再访问对应端口。关闭浏览器不会结束服务；在启动终端按 Ctrl+C 并等待退出。

## 先用示例熟悉流程

首页点击「先试一个例子」。示例的材料、问题和结果都是固定合成数据，页面明确标记「示例演示 · 未调用模型」，不会消耗模型额度，也不会写入真实项目库。

在示例里查看日期冲突、预算占位文字、版本选择与缺失附件，再进入交付预览。示例状态保存在当前浏览器标签页，不应作为真实项目保存方式。

## 使用自己的材料

1. 点击「开始收尾」，填写项目名称、接收者和目标。
2. 选择材料用途，导入要求、方案或参考资料，点击读取文字。
3. 在原文预览确认文字和定位可用；留意扫描页、复杂 Office 内容等覆盖提示。
4. 配置自己的模型，明确同意发送本次选定文字，提取候选要求。
5. 修改并确认要求清单，开始核对，再逐项查看证据与处理问题。
6. 修改原件后导入新版本并重新检查。模型不会替你直接修改原件。
7. 进入「准备交付」，选择版本与附件，确认说明，生成并下载 ZIP 和独立 HTML 报告。

支持 TXT、MD、DOCX、PDF。每项目最多 30 份快照、合计 100 MiB，单份最多 20 MiB；旧版本也计入容量。PDF 最多 100 页，项目解析文字最多 200000 码点。详细限制见 [本地数据说明](local-data.md)。

## 配置模型

打开「自有模型设置」，填写以下参数：

| 参数 | 如何填写 |
|---|---|
| 连接名称 | 自己容易辨认的名称 |
| 服务地址 | 服务商提供的 Chat Completions 兼容 base URL，通常以 `/v1` 结尾；不要填写完整请求路径 |
| 模型 ID | 使用你账号实际可用的模型或接入点 ID |
| 上下文容量 / 输出上限 | 按模型实际规格填写，不把其他模型的数值照搬过来 |
| API Key | 在本机界面输入，勿发到 Issue、截图、聊天或提交记录 |

远程服务要求 HTTPS。本机无需鉴权的服务可以明确选择「仅本机服务，无需密钥」。当前支持的是兼容接口格式，尚不支持厂商原生协议或额外请求头。

保存参数不会调用模型；重启也不会自动探测。只有你点击「测试连接」或主动进行 AI 抽取/核对才会发出模型请求，并可能收费。模型处理数据的方式受所选供应商的服务条款约束。

## 保存模型密钥

默认 Key 仅保留在当前服务内存，重启后需要重新输入。普通参数会自动恢复。

如需系统 Keychain 保存，并已安装 Apple Command Line Tools，可在项目目录运行：

```bash
npm exec --yes --package=pnpm@11.28.5 -- pnpm build:keychain
```

重新启动服务，在模型设置页明确选择保存到 macOS Keychain。辅助程序不可用时维持本次内存保存，不会退回明文文件。系统 Keychain 不在应用数据备份中，换机器需要重新配置。

## 文件、历史与备份

默认目录为 `~/Library/Application Support/Shouwei Buddy/`。在「本地数据」页查看实际位置、删除项目或预览诊断。备份时先退出服务，再复制整个数据目录；不要只复制 SQLite 而漏掉快照和交付包。

删除项目保留用户原件、已完成交付和迁移备份。收件人的 ZIP 与自己的检查报告分别下载；浏览器取消保存，不会删除已生成的历史记录。

## 常见情况

- **扫描 PDF 没有文字**：当前没有 OCR，请先用自己的工具识别或提供可提取文字的副本。
- **状态为未完成/范围不完整**：处理覆盖缺口并重新检查，不把缺口视为已通过。
- **重启后要重新输入 Key**：这是默认的仅本次保存行为，可选择 Keychain。
- **强退后提示目录被占用**：先确认原服务已退出，按 [恢复说明](local-data.md#备份与恢复) 处理锁；不要同时启动两个服务读写一个目录。
- **Windows 能否运行**：当前暂不支持，不能把存在跨平台路径分支理解为已完成适配。
