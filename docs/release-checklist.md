# 发行清单

当前版本为 0.1.0-rc.1 开源源码预览版，暂时仅支持 Mac / Apple Silicon。本地已有未签名候选，不将其视为正式安装发行。

| 项目 | 状态 | 下一步或证据 |
|---|---|---|
| 本地源码、锁文件与文档 | 已准备 | README、架构、使用指南、合成示例截图及贡献说明 |
| 配置、Keychain 可选保存、删除与诊断 | 本机已验 | 单元、集成与浏览器测试 |
| 包内资源和业务闭环 | 本机已验 | 实际包内 Node/SDK、导出、重启与退出；合成模型，付费请求 0 |
| 源码发布边界 | 自动已验 | 明确文档允许清单、凭据/数据库/私人目录排除、嵌套许可保留 |
| 类型、测试、审计 | 见 verification.md | 发布前按改动范围复核 |
| 新 Mac 无开发工具安装 | 待验 | 干净 macOS Apple Silicon 实机，完整走一遍配置与交付 |
| Intel Mac / 其他 macOS / Windows / Linux | 暂不支持 | 需要各自实现与实机验证，不能由路径分支推定支持 |
| Developer ID 签名与公证 | 待验 | 真实签名与 Gatekeeper 验证，不关闭系统保护 |
| 五位新用户 | 待安排 | 记录安装、配置、示例、材料与退出的耗时及卡点 |
| 真实模型业务质量 | 待单独验收 | 用户明确授权和费用范围后，用真实任务标准评估 |
| 90 秒真实模型录像 | 待制作 | 如实标注模型、样例和剪辑；合成截图不能代替 |
| 二进制公开分发许可 | 待复核 | 检查上游版权、嵌套资源、NOTICE 及 LGPL/MPL 等源码提供义务 |

许可清单要求每个包映射非空正文，但部分发布包缺少原文，当前有明示的补充条款。技术门禁不能证明完整法律合规。源码与上游依赖分开发布；正式二进制附件要完成本表对应门禁。

测试平台和细节见 [验证记录](verification.md)。
