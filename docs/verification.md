## 公开仓库整理

README 截图来自实际界面和内置示例，使用隔离数据目录、没有模型请求，也不包含私人项目。截图没有把合成结果标为真实模型质量。

源码打包回归先复现公开清单不完整和内部文档进入包的问题，再验证修复：保留 .github 模板和嵌套许可正文，排除内部记录、未知私人目录、环境文件、数据库和依赖缓存。

## 关键边界

- schema 迁移前创建可读备份，失败事务回滚；旧 revision 和活动任务阻止冲突修改。
- 删除保留原件与完成交付；损坏清理记录不阻断其他项目。死亡所有者会话可清理，活进程、其他项目、未知目录和链接目标保留。
- 候选引文必须回到实际材料；更新材料或要求后，旧结论失效。未完成范围及技术缺口不能通过风险理由放行。
- ZIP 实际解包校验附件摘要；报告 HTML 转义并限制脚本，CSV 防公式注入；下载前复核产物。
- 普通参数与密钥分离，安全存储失败不回退明文。诊断响应只含白名单状态与计数。
- 567 个实际生产包均有非空许可正文映射；14 项使用明示补充 NOTICE/SPDX，完整法律合规仍需独立复核。

保留一项已知低优先级问题：诊断 activeRuns 计数内部仍使用完整项目查询，多读取了列；响应不返回这些私人列。后续可收窄为仅计数的 SQL。
